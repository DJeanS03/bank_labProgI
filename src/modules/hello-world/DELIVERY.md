# Entrega 2 — Scaffold Clean Architecture (Hello World)

## ✅ Escopo Entregue

Este módulo segue o padrão Clean Architecture e contém a estrutura física organizada com:

- Camada **interface**: contratos públicos (IHelloController, IHelloPresenter) e DTOs (HelloRequestDTO, HelloResponseDTO)
- Camada **use-case**: interface de caso de uso (IHelloUseCase)
- Camada **domain**: entidade Hello
- Camada **infra**: stubs (HelloControllerAdapterStub, HelloRepositoryStub)
- Index de exportação pública
- Documentação por camada (README.md em cada pasta)
- Este DELIVERY.md + checklist de QA
